# Implementation Plan: UI Fixes — Countdown Card, Historical Chart Legend, Ice Rink Icon

**Branch**: `005-ui-fixes-countdown-chart-icon` | **Date**: 2026-05-06 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `/specs/005-ui-fixes-countdown-chart-icon/spec.md`

## Summary

Three targeted frontend-only UI fixes to the PoolTracker React dashboard:

1. **Countdown card** — move the "days until aquapark opening" counter out of the hidden
   `isEmpty` fallback sections (`CurrentOccupancy`, `TodayChart`) and into a permanent
   `CountdownCard` component placed in the `extra-cards` row alongside `WeatherCard` and
   `FacebookCard`. The card reuses the `['current']` TanStack Query cache — no extra
   network requests and no backend changes.

2. **Historical chart tooltip fix + data filtering** — correct the ApexCharts tooltip so
   it displays the actual HH:MM time label instead of the 1-based point index. Additionally,
   filter out data points with a time before `06:00` on the frontend to prevent late-night
   scrapper artefacts (stored as `23:xx` after the backend's −1 h UTC correction) from
   appearing at the left edge of the chart.

3. **Ice rink icon** — add an `icon` field to the `POOLS` constant in `CurrentOccupancy.jsx`
   and replace the hardcoded 🏊 emoji with `pool.icon`, setting the ice entry to ⛸️.

## Design Decisions

### CountdownCard styling

`CountdownCard` reuses the existing `.weather-card` CSS class (same card style as
`WeatherCard`). This avoids adding new CSS and maintains visual consistency in the
`extra-cards` row. The card structure:

```jsx
<article className="weather-card" aria-label="Odliczanie do otwarcia aquaparku">
  <div className="weather-card__title">Aquapark</div>
  <div className="countdown-card__days">{opening}</div>
  <div className="weather-card__desc">dni do otwarcia</div>
</article>
```

When `opening <= 0`:

```jsx
<div className="weather-card__desc">Aquapark jest już otwarty! 🎉</div>
```

### HistoricalChart filter + tooltip fix

```js
// Filter indices where time >= '06:00'
const validIndices = data.date_stat
  .map((t, i) => (t >= '06:00' ? i : -1))
  .filter((i) => i !== -1)

const filteredCategories = validIndices.map((i) => data.date_stat[i])
const filteredSport      = validIndices.map((i) => data.sport_stat[i])
// ...

// Tooltip fix (closure over filteredCategories)
tooltip: {
  x: { formatter: (val, opts) => filteredCategories[opts.dataPointIndex] ?? val },
  y: { formatter: (val) => `${val} os.` },
}
```
