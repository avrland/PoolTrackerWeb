# Material Symbols

`paths.json` contains unmodified path data from the 24px Rounded and Outlined SVGs in
https://github.com/google/material-design-icons/tree/master/symbols/web

Each key is `variant/name`. Source file:
`symbols/web/{name}/materialsymbols{variant}/{name}_24px.svg`.
`fiber_manual_record`, `navigation` and `directions` use `{name}_fill1_24px.svg`.
The SVG viewBox is `0 -960 960 960`.
